# Dataset Description

## Overview

This dataset contains Human Resources (HR) employee information and is used for workforce analytics, employee profiling, salary analysis, demographic analysis, and leave management reporting.

The dataset consists of employee records with details related to personal information, education, job roles, compensation, and leave balances.

---

## Dataset Summary

| Attribute     | Description      |
| ------------- | ---------------- |
| Total Records | 161 Employees    |
| Total Columns | 9 Fields         |
| Data Type     | Employee HR Data |
| File Format   | Excel (.xlsx)    |

---

## Column Description

### 1. Name

Employee's full name.

**Example:** Barr Faughny

### 2. Emp ID

Unique employee identifier assigned to each employee.

**Example:** AC0001

### 3. Gender

Employee gender information.

**Values:** Male, Female

### 4. Education Qualification

Highest educational qualification attained by the employee.

**Examples:** Bachelor's Degree, Master's Degree, PhD, Diploma

### 5. Date of Join

Date on which the employee joined the organization.

**Format:** Date

### 6. Job Title

Designation or role assigned to the employee.

**Examples:** Analyst, Manager, Engineer, Consultant

### 7. Salary

Annual salary of the employee.

**Data Type:** Numeric

### 8. Age

Employee age in years.

**Data Type:** Numeric

### 9. Leave Balance

Number of remaining leave days available to the employee.

**Data Type:** Numeric
